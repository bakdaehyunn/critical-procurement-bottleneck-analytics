# Ontology-Native Documentation Status

Files named `phase1_...` through `phase20_...`, `post_phase20_...`, and other
dated design slices in this directory are historical implementation records
unless they appear in the active list below. They describe the state and
constraints at the time of each checkpoint and are not current capability
authority. In particular, `ontology_action_layer_v1.md` records the earlier
disabled-action design and is superseded by the current API/action contract.

Use these documents for the active design:

- `README.md`
- `docs/01_architecture.md`
- `docs/04_api.md`
- `docs/05_ui_spec.md`
- `docs/06_verification_plan.md`
- `docs/10_operational_case_study.md`
- `docs/capability_truth_ledger.md`
- `docs/current_limitations.md`
- `docs/ontology-native/query_catalog_ownership_v1.md`
- `docs/ontology-native/layer_consolidation_hardening_v1.md`

When a historical phase note conflicts with an active document or executable
contract test, the active document and test define current behavior.
