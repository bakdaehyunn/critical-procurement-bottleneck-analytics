# Controlled AI Proposal Fixtures

These local `.properties` files describe deterministic AI governance proposal
inputs for the internal ontology-native runtime.

They are not generated by an external AI API. They simulate model output so the
platform can validate AI proposal provenance, confidence policy, risk metadata,
managed `ai-audit` graph writes, and review read models without granting AI any
authority to mutate canonical, reasoning, operations, source, or production
graphs.
